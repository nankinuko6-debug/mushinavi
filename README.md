# ムシナビ v0.1

虫で困ったときに「まず確認できる場所」を目指す、スマホ向けプロトタイプです。

## v0.1でできること

- 虫の写真をブラウザで選択
- 写真プレビュー
- 場所・大きさ・巣の有無によるルールベースの簡易判定
- 危険度・対処の目安表示
- デモ用の目撃MAP
- 目撃情報をブラウザのlocalStorageへ保存

## 重要

このバージョンは**AI画像認識には接続されていません**。
`app.js` の `classify()` がv0.1のデモ判定ロジックです。

次のバージョンでは、ここを画像認識API等へ置き換えます。

また、実際の位置情報を扱うサービスとして公開する場合は、個人情報、位置情報、投稿内容の安全性、誤判定時の表示、利用規約、プライバシーポリシー等を別途整備してください。

## GitHub Pagesへの公開

1. GitHubで新しいリポジトリを作成
2. `index.html`, `style.css`, `app.js`, `README.md` をアップロード
3. Settings → Pages
4. Deploy from a branch を選択
5. `main` / `root` を選択して保存
6. 発行されたURLを開く

GitHub Pagesは静的サイトなので、このv0.1はそのまま公開できます。
