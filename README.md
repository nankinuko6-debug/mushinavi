# ムシナビ v0.2（蜂・マダニ特化版）

現在のURL `https://nankinuko6-debug.github.io/mushinavi/` のGitHub Pagesリポジトリに、この4ファイルを上書きアップロードしてください。

## 変更点
- 対象を「蜂」と「マダニ」に限定
- トップページを2択入口に変更
- 蜂用の確認フローを追加
- マダニ用の確認フローを追加
- 危険度の表示を蜂/マダニ別に整理
- 目撃MAPを蜂・マダニだけに変更
- 対策ガイドを蜂・マダニ中心に変更
- v0.1のURL・リポジトリ名は変更不要

## 差し替え手順
1. GitHubの `mushinavi` リポジトリを開く
2. `index.html` / `style.css` / `app.js` をそれぞれ開く
3. 鉛筆アイコンから中身を置き換える、または Upload files で3ファイルを上書きする
4. Commit changes
5. 1〜数分待つ
6. `https://nankinuko6-debug.github.io/mushinavi/` を再読み込み

## 注意
このv0.2はまだAI画像認識には接続していません。写真はブラウザ内で表示するだけで、画像をAIサービスへ送信していません。
判定ロジックはプロトタイプです。医療診断・害虫の確定同定・駆除判断を提供するものではありません。
